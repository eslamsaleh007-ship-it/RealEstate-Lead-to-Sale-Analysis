# Real Estate Lead-to-Sale Analysis

## Project Overview

A Real Estate Data Analytics project that analyzes the customer journey from the initial lead to the final property sale.

The project aims to identify conversion rates, funnel drop-offs, lead source performance, sales agent performance, and factors that may affect successful property sales.
